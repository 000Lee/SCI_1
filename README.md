## 1-1. 척수(spinal cord)의 구조

### ① 정의

큰구멍(foramen magnum)에서 시작해 성인 기준 **첫째~둘째 허리뼈(L1~L2) 높이에서 끝난다.**

- 척수원뿔(conus medullaris): 척수가 끝나는 원뿔 모양 부분
- 말총(cauda equina): 그 아래로 뻗어 내려가는 신경뿌리 다발

**단면 구조**

| 구역 | 내용 |
|---|---|
| 앞뿔(anterior horn) | 하위운동신경세포(lower motor neuron, LMN)의 **세포체** |
| 뒤뿔(posterior horn) | 감각 입력 중계 |
| 가쪽뿔(lateral horn) | **T1~L2에만 존재.** 교감신경 신경절이전신경세포 |
| 백색질(white matter) | 전도로(tract)가 지나가는 고속도로 |

**팽대부(enlargement)** — 신경세포가 몰려 굵어진 곳

- 목팽대(cervical enlargement) C4~T1 → 팔신경얼기(brachial plexus)
- 허리엉치팽대(lumbosacral enlargement) L1~S3 → 다리

### ② 기전 — 혈액공급

| 동맥 | 개수 | 담당 |
|---|---|---|
| 앞척수동맥(anterior spinal artery) | **1개** | 앞쪽 2/3 (겉질척수로 + 척수시상로) |
| 뒤척수동맥(posterior spinal artery) | **2개** | 뒤쪽 1/3 (뒤기둥) |

앞쪽은 동맥 1개에 의존 → 허혈에 취약 → 전척수증후군(anterior cord syndrome)에서 **운동·통각은 나가고 고유감각은 남는** 이유. 대동맥 수술 후 T4~T6 분수령(watershed) 부위에서 호발.

### ③ 임상양상 — 뇌졸중과의 결정적 차이

| | 뇌졸중(stroke) | 척수손상(SCI) |
|---|---|---|
| 손상 신경세포 | 항상 상위운동신경세포(UMN) | 손상 높이에 따라 다름 |
| 원뿔 **위** 손상 | — | UMN 양상(경직, 반사 항진) |
| 원뿔/말총 손상 | — | **LMN 양상**(이완, 반사 소실, 근위축) |

> **핵심**
> 뇌졸중 환자는 100% UMN이다.
> 척수손상 환자는 "이 환자가 UMN인가 LMN인가"를 **먼저** 판단해야 한다.
> L1 아래는 사실상 말초신경 손상이라, 경직 치료 전략을 그대로 적용하면 안 된다.

### ④ 치료실 대응

환자 파일을 열면 **가장 먼저 손상 부위가 원뿔 위인지 아래인지** 확인한다.

- **원뿔 위**: 경직 관리, 반사 이용, 기립·보행훈련에 반사 활용 여지 있음
- **원뿔/말총**: 이완성 마비, 근위축 빠름, 관절 보호 최우선, 근력강화는 남은 근육 중심

## 1-2. 척수분절 ≠ 척추뼈 번호

### ① 정의

척수분절(spinal segment) 번호와 그것을 감싸는 척추뼈(vertebra) 번호가 **아래로 갈수록 벌어진다.**

### ② 기전

태아기에 척추뼈가 척수보다 빨리, 길게 자란다. 척수는 위쪽에 매달린 채 남고 신경뿌리만 아래로 길게 늘어진다.

**대략적 보정값**

| 척추뼈 부위 | 보정 |
|---|---|
| 목뼈(cervical) | 번호 **+1** |
| 위쪽 등뼈(T1~T6) | 번호 **+2** |
| 아래쪽 등뼈(T7~T12) | 번호 **+3** |
| **T11~L1 척추뼈** | 안에 **허리·엉치 분절 전체**가 압축되어 있음 |

### ③ 임상양상 — 여기서 실수가 많이 난다

"T12 압박골절, 척추고정술 시행" 기록을 보고 "T12 손상이니 몸통은 되겠네"라고 판단하면 **틀린다.**
T12 척추뼈 안에는 L2~S 분절이 들어 있어, 실제로는 **말총증후군(cauda equina syndrome)에 가까운 이완성 하지마비**일 수 있다.

반대로 "C5 골절"인데 신경학적으로 C6 기능이 남아 있는 경우도 흔하다.

### ④ 치료실 대응

- **영상 레벨(골절 부위)과 신경학적 손상 레벨(NLI)을 기록에 반드시 분리해서 적는다.**
  - 예) `T12 압박골절 / NLI L1 / AIS B`
- 치료 계획은 **골절 부위가 아니라 신경학적 레벨로 세운다.**
- 척추 고정술 후 몸통 움직임 제한 범위(굽힘·회전 금지 기간, 보조기 착용 기간)
  → **⚠️ 병원·집도의마다 다르므로 반드시 확인 필요.**

## 1-3. 피부분절(dermatome)과 근육분절(myotome)

### ① 정의

- **피부분절**: 하나의 뒤뿌리(dorsal root)가 담당하는 **피부 영역**
- **근육분절**: 하나의 앞뿌리(ventral root)가 담당하는 **근육군**

### ② 기전 — 두 가지 중요한 성질

**(1) 피부분절은 서로 겹친다(overlap).**
인접 분절이 20~30% 겹치므로 한 분절만 손상되면 감각 소실이 거의 안 나타난다.
→ 감각 경계가 뚜렷하다는 것 자체가 **여러 분절이 한꺼번에 나갔다**는 뜻.

**(2) 근육은 대부분 2~3개 분절의 지배를 받는다.**
한 분절이 완전히 죽어도 근력이 0이 되지 않고 **약해진 상태(MMT 3점 전후)** 로 남는다.
→ 2단계의 "운동레벨 = MMT 3점 이상인 가장 낮은 분절" 정의가 여기서 나온다.

### ③ 임상양상 — 외워야 할 랜드마크

#### 감각 랜드마크

| 분절 | 위치 |
|---|---|
| C4 | 어깨 위·빗장뼈 부위 |
| C6 | **엄지** |
| C7 | **중지** |
| C8 | **새끼손가락** |
| T4 | **젖꼭지선** |
| T6 | 칼돌기(xiphoid process) |
| T10 | **배꼽** |
| T12 | 샅고랑(inguinal) |
| L3 | 무릎 안쪽 |
| L4 | 안쪽복사(medial malleolus) |
| L5 | 발등 3번째 발허리발가락관절 |
| S1 | 발꿈치 가쪽 |
| S4~5 | **항문 주위** |

> **최소한 이 셋**: T4=젖꼭지, T10=배꼽, S4~5=항문 주위

#### 근육분절 — 상지

| 분절 | 근육 | 작용 |
|---|---|---|
| C3~C5 | 가로막(diaphragm) | 들숨 |
| C4 | 등세모근 위섬유(upper trapezius) | 어깨뼈 올림 |
| C5 | 위팔두갈래근·위팔근(biceps brachii, brachialis) | 팔꿈치 굽힘 |
| C5 | 어깨세모근(deltoid) | 어깨 벌림 |
| C6 | 긴·짧은노쪽손목폄근(extensor carpi radialis longus/brevis) | **손목 폄** |
| C6~C8 | 넓은등근(latissimus dorsi) | 어깨 폄·모음 |
| C7 | 위팔세갈래근(triceps brachii) | **팔꿈치 폄** |
| C8 | 깊은손가락굽힘근(flexor digitorum profundus) | 손가락 굽힘 |
| T1 | 새끼벌림근(abductor digiti minimi) | 새끼손가락 벌림 |

#### 근육분절 — 몸통·하지

| 분절 | 근육 | 작용 |
|---|---|---|
| T2~T12 | 갈비사이근(intercostals) | 날숨·기침 |
| T6~T12 | 배곧은근(rectus abdominis) | **몸통 굽힘·기침** |
| L2 | 엉덩허리근(iliopsoas) | 엉덩관절 굽힘 |
| L3 | 넙다리네갈래근(quadriceps femoris) | **무릎 폄** |
| L4 | 앞정강근(tibialis anterior) | 발등굽힘 |
| L5 | 긴엄지폄근(extensor hallucis longus) | 엄지 폄 |
| S1 | 장딴지근·가자미근(gastrocnemius, soleus) | 발바닥굽힘 |

### ④ 치료실 대응 — 세 개의 분기점

**C6 vs C7 — 옮겨앉기(transfer) 독립의 분기점**
C7의 위팔세갈래근(triceps brachii)이 있어야 팔꿈치를 펴서 몸을 밀어올린다.
C6까지면 팔꿈치 폄근이 없어 **어깨 바깥돌림 + 팔꿈치 잠금** 대체 전략을 가르쳐야 한다.

**C5 vs C6 — 텐노데시스 잡기(tenodesis grasp)의 분기점**
C6의 노쪽손목폄근이 살아야 손목을 젖히고, 그때 손가락굽힘근이 수동적으로 당겨지며 잡기가 된다. (3단계 상세)

**T6~T12 — 앉은 균형의 분기점**
배곧은근(rectus abdominis)이 T6~T12 지배. 이 분절이 나가면 **몸통을 굽혀 균형을 잡을 수 없고, 기침을 못 한다.**

> **뇌졸중과의 차이 — 이 자료 전체에서 가장 중요한 문장**
> 뇌졸중은 "연결은 있는데 조절이 안 되는" 상태 → 촉진(facilitation)·재학습이 유효.
> 척수손상 완전손상 아래 분절은 **연결 자체가 끊긴** 상태 → 촉진해도 안 나온다.
> **없는 근육을 살리려 시간 쓰지 말고, 남은 근육의 재편성에 시간을 쓴다.**

## 1-4. 주요 전도로(tract)

### ① 정의 및 요약

| 전도로 | 기능 | 교차 위치 | 손상 시 증상 쪽 |
|---|---|---|---|
| 가쪽겉질척수로(lateral corticospinal tract) | 수의적 운동 | **숨뇌(medulla)** 피라미드교차 | **같은쪽(ipsilateral)** |
| 척수시상로(spinothalamic tract) | 통각·온도 | **척수 내, 1~2분절 위** | **반대쪽(contralateral)** |
| 뒤기둥(dorsal column) | 고유감각·진동·식별촉각 | **숨뇌** 뒤기둥핵 | **같은쪽(ipsilateral)** |

> ### 🔑 한 줄로 외울 것
> **척수 안에서 교차하는 건 통각·온도(척수시상로) 하나뿐이다.**
> **나머지는 전부 척수보다 위에서 이미 교차하고 내려온다.**

### ② 기전

#### 겉질척수로(corticospinal tract)

운동겉질 → 숨뇌 피라미드교차(pyramidal decussation)에서 약 90%가 반대쪽으로 → 척수 **가쪽**을 타고 하행.

> **필요한 건 이 한 문장뿐이다.**
> 운동 명령은 뇌 바로 아래(숨뇌)에서 이미 반대편으로 넘어간다.
> **척수에 도착했을 땐 이미 넘어간 상태다. 그래서 척수는 같은 쪽.**

| | 손상 부위 | 마비 쪽 | 이유 |
|---|---|---|---|
| 뇌졸중 | 좌측 뇌 | **우측** | 교차 **전** 손상 |
| 척수손상 | 우측 척수 | **우측** | 교차 **후** 손상 |

#### 척수시상로(spinothalamic tract)

통각·온도 신호가 뒤뿌리로 들어와 → 뒤뿔에서 시냅스 → **척수 안에서 1~2분절 올라간 뒤** 앞백색교차(anterior white commissure)를 건너 반대쪽 앞가쪽으로 상행.

→ 그래서 감각 소실 경계가 실제 손상 부위보다 **1~2분절 아래**로 나타난다.

#### 뒤기둥(dorsal column)

고유감각·진동·두점식별. **교차하지 않고** 같은쪽 뒤쪽을 그대로 올라가 숨뇌에서 시냅스 후 교차.

- 널판다발(gracile fasciculus): 안쪽, **T6 이하 = 하지**
- 쐐기다발(cuneate fasciculus): 가쪽, **T6 위 = 상지**

#### 겉질척수로 외 하행로 (놓치기 쉬움)

그물척수로(reticulospinal tract), 안뜰척수로(vestibulospinal tract)
→ **자세 조절, 몸통 근육, 폄근 긴장** 담당. 척수 안쪽에 위치.
겉질척수로가 손상돼도 이 경로가 남아 있으면 몸통 조절·기립 반응이 일부 회복될 수 있다.

> **근거 강도**: 불완전손상 보행 회복에 이 경로들이 기여한다는 것은 **가능성 수준**. 확립된 사실로 말하지 말 것.

#### 중심척수증후군 기전 — 외우지 말 것

체성분포(somatotopic organization) 배열 때문이라는 설명과, 손 기능의 겉질척수로 의존도 때문이라는 설명이 **학계에서 갈린다.**

> **기전은 버리고 소견만 기억한다.**
> 중심척수증후군(central cord syndrome) = **팔이 다리보다 더 나쁘다.** 끝.

### ③ 임상양상

- **뒤기둥이 남았는가**가 균형훈련 예후를 크게 가른다.
  - 남음 → 시각 보상 + 고유감각으로 기립 훈련 진행 가능
  - 소실 → 시각에 100% 의존. **어두운 곳·머리 돌릴 때 즉시 무너진다.**
- **척수시상로만 나간 경우**(전척수증후군 등) → 통각·온도는 못 느끼는데 위치 감각은 있음
  → **화상·동상·압박 손상에 극도로 취약.**

### ④ 치료실 대응

평가 시 **운동 / 통각·온도 / 고유감각·진동을 반드시 따로 확인한다.**
"감각 저하"라고 한 줄로 적으면 정보가 없다.

- 통각 소실 부위 → 핫팩·아이스팩 **금기 수준으로 주의**, 온도 치료 전 반드시 확인
- 고유감각 소실 → 균형훈련에 거울·시각 표적 도입, 조도 확보

## 1-5. 자율신경계(autonomic nervous system)

> 척수손상이 뇌졸중과 가장 다른 지점이고, **환자를 죽일 수도 있는 영역.**

### ① 정의 — 두 계통의 출구가 다르다

**교감신경(sympathetic): T1~L2 가쪽뿔에서만 나온다.**

| 분절 | 지배 |
|---|---|
| T1~T4 | 심장 (심장가속신경, cardiac accelerator nerve) |
| T5~L2 | 배안 내장혈관(splanchnic vascular bed) — **혈압 유지의 핵심 저장고** |

**부교감신경(parasympathetic): 두 군데서 나온다.**

- 뇌신경 — 특히 **미주신경(vagus nerve, CN X)**: 심장·소화기
- 엉치 S2~S4: 방광 배뇨근(detrusor), 직장, 발기

### ② 기전 — 왜 척수손상 환자는 혈압이 낮고 맥이 느린가

> **미주신경은 척수를 통과하지 않는다. 목에서 바로 내려간다.**

목척수손상(tetraplegia) 환자:

- 교감신경(T1~L2)은 뇌의 조절에서 **끊김** → 혈관수축 명령 못 감, 심박수 못 올림
- 미주신경은 **멀쩡함** → 심장을 계속 느리게 누름
- 결과: **저혈압 + 서맥(bradycardia)**

목척수손상 환자의 기저 수축기혈압 90~110mmHg는 흔하며, **그것이 그 환자의 정상이다.**

**T6가 왜 마법의 숫자인가**

큰내장신경(greater splanchnic nerve)이 대략 T5~T9에서 나와 배안 혈관을 지배.
손상이 T6보다 높으면 이 거대한 혈관상 전체가 뇌의 통제 밖 → **AD 위험선.**

> **단서**: T6는 관례적 기준선이고 T7~T8 손상에서도 보고된다.
> "T6 이상**만** 위험"이 아니라 "T6 이상은 **반드시** 위험"으로 이해할 것.

### ③ 임상양상 — 방광

| | 원뿔 **위** 손상 (UMN 방광) | 원뿔/말총 손상 (LMN 방광) |
|---|---|---|
| 양상 | 배뇨근 과활동 + 배뇨근-조임근 협동장애(DSD) | 이완성, 넘침요실금(overflow incontinence) |
| 위험 | 방광은 짜는데 조임근이 안 열림 → 고압 방광 → **신장 손상** | 잔뇨, 요로감염 |

**치료사에게 왜 중요한가**

간헐적 도뇨(intermittent catheterization, IC)는 보통 **4~6시간 간격**.
이 스케줄을 모르고 치료 시간을 잡으면 방광이 꽉 찬 상태로 훈련하게 되고,
그것이 **AD의 가장 흔한 유발 원인**이 된다.

→ **도뇨 직후 시간대("골든 윈도우")에 치료를 배치한다.**

## ⚠️ 응급 — 자율신경 반사부전(autonomic dysreflexia, AD)

> 5단계에서 상세히 다루지만, 병동에 나가는 순간부터 필요하므로 최소한을 여기 둔다.

### 의심 기준

- 손상 **T6 이상** (또는 그 근처)
- **수축기혈압이 그 환자의 기저치보다 20~40mmHg 상승**
  - 기저 90인 환자의 혈압 130은 **정상이 아니라 위기다.**
  - → **담당 환자의 기저 혈압을 미리 적어둘 것. 없으면 AD를 알아볼 수 없다.**
- 동반 증상
  - 터질 듯한 두통
  - 손상 부위 **위쪽**: 얼굴·목 홍조, 발한
  - 손상 부위 **아래쪽**: 창백, 소름
  - 코막힘, 서맥, 불안감

### 즉시 조치 순서

| 순서 | 조치 |
|---|---|
| **1** | **치료 즉시 중단. 환자를 앉힌다.** ⚠️ 눕히지 말 것 — 머리 올리고 다리 내려서 혈압을 떨어뜨린다 |
| **2** | **조이는 것 전부 푼다** — 복대(abdominal binder), 압박스타킹, 벨트, 신발, 보조기 |
| **3** | **혈압 측정 + 간호사·의사 즉시 호출** (동시에. 혼자 원인 찾다 시간 끌지 말 것) |
| **4** | **유발 원인 탐색 (빈도순)** |
| | ① **방광 (약 75~85%)** — 도뇨관 꺾임·눌림·막힘, 소변주머니 가득 참, 도뇨 시간 지남 |
| | ② **장** — 변매복(fecal impaction), 직장 팽만 |
| | ③ **피부** — 욕창, 파고든 발톱, 조이는 옷, 화상, 골절 |
| **5** | 원인 제거될 때까지 **2~5분 간격 혈압 재측정** |

> **⚠️ 병원 지침 확인 필요 — 입사 후 가장 먼저 확인할 두 가지**
> 1. 약물 투여(nifedipine, nitrate 계열) 프로토콜
> 2. **치료사가 도뇨관 조작·직장 처치를 할 수 있는 범위**

### ⚠️ 기립성 저혈압(orthostatic hypotension)

AD보다 훨씬 흔하다.

- 기립 훈련 **전** 혈압 측정
- 기립 **중** 어지럼·시야흐림·하품·창백 확인
- 발생 시 **즉시 뒤로 눕히고 다리 올림**
- 예방: 복대·압박스타킹, 점진적 기립 각도 증가

## 이해도 확인 질문 + 해설

### Q1. 오른쪽 척수의 절반이 손상된 환자. 운동마비는 어느 쪽, 통각 소실은 어느 쪽인가?

**세로로 반쪽만 손상되는 것, 실제로 있다** → 브라운세카르증후군(Brown-Séquard syndrome)

원인: 칼에 찔림, 총상, 한쪽 돌기관절(facet) 골절·탈구, 한쪽 종양 압박, 디스크가 한쪽으로 심하게 밀림.
※ 교과서처럼 딱 반쪽만 깨끗이 잘리는 경우는 드물고, 실제로는 "한쪽이 더 나쁜" 형태로 온다.

**정답**

| | 어디서 교차 | 오른쪽 척수 손상 시 |
|---|---|---|
| 운동 | 척수 **위쪽**(숨뇌) | **오른쪽** 마비 |
| 고유감각·진동 | 척수 **위쪽**(숨뇌) | **오른쪽** 소실 |
| 통각·온도 | **척수 안에서** | **왼쪽** 소실 |

왼쪽에서 들어온 통각 신호가 척수 안에서 오른쪽으로 건너와 올라간다.
→ 오른쪽이 다치면 **왼쪽 통각**이 나간다.

**환자 모습**

- 오른쪽 다리: 안 움직이는데, 꼬집으면 아프다고 함
- 왼쪽 다리: 움직이는데, 뜨거운 걸 못 느낌

> **치료실 대응**: 화상 위험은 **움직이는 왼쪽 다리**에 있다. 이게 이 증후군의 함정이다.

### Q2. "T12 압박골절, 하지 완전마비" — 경직 관리 계획을 세워도 되는가?

**안 된다. 먼저 UMN인지 LMN인지 확인해야 한다.**

T12는 척추뼈 번호일 뿐. 그 안의 척수분절은 L2~S.
즉 척수원뿔~말총 구간일 가능성이 높고, 그렇다면 **LMN 손상 = 이완성 마비**.
경직이 아예 안 생기므로 **경직 관리 계획 자체가 성립하지 않는다.**

**어떻게 확인하나 — 영상이 아니라 진찰로 확인한다**

| 확인 항목 | UMN | LMN |
|---|---|---|
| 근긴장 | 경직(spasticity) | 이완(flaccid) |
| 무릎힘줄반사·발목반사 | 항진 | 소실 |
| 항문반사·구해면체반사(bulbocavernosus reflex) | 있음 | 없음 |
| 근위축 | 느림 | **빠르고 심함** |
| 발바닥반사 | 바뱅스키 양성 | 무반응 |

> **⚠️ 함정**: 척수쇼크(spinal shock) 시기에는 UMN 손상이어도 전부 이완성으로 나온다.
> 손상 후 며칠~몇 주 이내라면 이 판단을 유보해야 한다. (4단계)

### Q3. C6 손상, 기립 훈련 중 두통·안면홍조. 혈압 135 (평소 95).

**판단: 40mmHg 상승 → AD**

135라는 절대값이 아니라 **기저 대비 상승폭**으로 판단한다.

**조치 순서**

1. 치료 중단, **앉힌다** (눕히지 않는다)
2. 조이는 것 전부 푼다 — 벨트, 복대, 압박스타킹, 신발, 보조기
3. **혈압 측정 + 간호사·의사 즉시 호출** (동시에)
4. 원인 탐색: **방광 → 장 → 피부** 순
5. 2~5분 간격 혈압 재측정

**가장 먼저 의심할 원인: 방광, 그중 도뇨관 꺾임/눌림.**
기립 훈련 중이었으니 벨트나 다리 위치로 관이 눌렸을 가능성이 크다.
**소변주머니가 비어 있으면(=소변이 안 나오고 있으면) 오히려 더 의심해야 한다.**

## 1단계 핵심 요약 카드

> 병동 나가기 전 이것만 다시 볼 것

1. **척수 안에서 교차하는 건 통각·온도 하나뿐.** 나머지는 위에서 이미 교차 → 같은 쪽.
2. **척추뼈 번호 ≠ 척수분절 번호.** 치료 계획은 NLI로 세운다.
3. **원뿔 위 = UMN(경직) / 원뿔·말총 = LMN(이완).** 환자 보면 이것부터 판단.
4. **T4=젖꼭지, T10=배꼽, S4~5=항문 주위.**
5. **C6 = 손목 폄(텐노데시스) / C7 = 팔꿈치 폄(옮겨앉기) / T6~T12 = 배곧은근(균형·기침).**
6. **뇌졸중의 촉진(facilitation)은 완전손상 아래 분절에서 통하지 않는다.** 남은 근육 재편성이 답.
7. **T6 이상 = AD 위험.** 기저 혈압을 미리 알아둘 것. 상승 20~40mmHg면 위기.
8. **AD 시: 앉히고 → 풀고 → 재고·부르고 → 방광·장·피부 순으로 찾는다.**
9. **감각은 운동/통각·온도/고유감각을 따로 기록한다.**
10. **⚠️ 병원 확인 필요 3가지**: 척추 수술 후 움직임 제한 / AD 약물 프로토콜 / 치료사의 도뇨·직장 처치 허용 범위
